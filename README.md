# Geomorfologia we wsi Borchówka

Mapy geomorfologii terenu i jego pokrycia w kwartale we wsi Borchówka powstałe w wyniku grupowej ekspedycji terenu w maju 2025 roku, w ramach studiów. Projekt w QGISie i powstałe mapy są mojego autorstwa.

Aby podejrzeć mapy i projekt w QGIS należy pobrać to repozytorium, rozpakować i uruchomić upragniony plik.
