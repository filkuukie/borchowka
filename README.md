# Geomorfologia we wsi Borchówka

Mapy geomorfologii terenu i jego pokrycia w kwartale we wsi Borchówka, w dolinie rzeki Borchówka biegnącej przez tzw. Wzniesienia Łódzkie. Mapy powstałe w wyniku grupowej ekspedycji i kartowania terenu w maju 2025 roku, w ramach studiów. Projekt w QGISie i powstałe mapy są mojego autorstwa.

Aby podejrzeć projekt w QGIS należy pobrać to repozytorium, rozpakować i uruchomić plik "projekt.qgz".
